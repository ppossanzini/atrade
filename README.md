# AutoTrade

Sistema di trading assistito con integrazione cTrader, gate di rischio deterministici, esecuzione persist-first e riconciliazione fail-closed.

Per una spiegazione completa e leggibile del funzionamento, delle modalità simulate/demo/live e della procedura di collaudo, consulta [Come funziona AutoTrade](docs/HowItWorks.md).
